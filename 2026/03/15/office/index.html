一条命令激活 Windows/Office（Microsoft 365）？使用 PowerShell 脚本轻松搞定！

在日常使用 Windows 或 Office（Microsoft 365） 的过程中，激活往往是绕不开的话题。很多朋友可能还在寻找各种激活工具、序列号，或者被繁琐的步骤困扰。其实，现在有一种非常简洁的方法——只需要一条 PowerShell 命令，就能自动完成激活。今天就带大家了解一下这条神奇的指令。

🚀 一条命令搞定激活

打开 PowerShell（管理员），Windows11及以上请选择打开终端(管理员)，复制粘贴下面这行代码并回车：

然后根据弹出的菜单提示，输入对应的数字即可激活 Windows 或 Office（Microsoft 365）。整个过程全自动，无需手动下载文件或输入密钥。

🔍 命令解析

这条命令由两部分组成：

  • irm：Invoke-RestMethod 的简写，用于从指定的 URL 下载内容。这里它会下载 https://get.activated.win 指向的脚本。
  • iex：Invoke-Expression 的简写，用于执行下载的脚本内容。

合起来就是：从网络下载一个脚本并直接在内存中运行。这是一种非常常见的“下载并执行”模式，尤其适合分发和运行激活脚本。

🧰 脚本背景

这个 URL get.activated.win 实际上是知名开源项目 Microsoft Activation Scripts (MAS) 的重定向地址。MAS 由 GitHub 用户 MassGrave 维护，是一个开源、透明的 Windows 和 Office（Microsoft 365） 激活脚本集合，支持：

  • HWID (数字许可证激活)：永久激活 Windows 10/11。
  • Ohook：永久激活 Office（Microsoft 365）（绕过方式）。
  • KMS：180 天激活（适用于 Windows 和 Office（Microsoft 365） 的批量版本）。
  • 在线 KMS：激活 Windows/Office（Microsoft 365） 的 GVLK 密钥。

脚本完全开源，代码公开在 GitHub 上，任何人都可以审查，因此相对安全可靠。

步骤

  1. 以 管理员身份 打开 PowerShell（在开始菜单搜索 PowerShell，右键选择“以管理员身份运行”，Windows11及以上请选择打开终端(管理员)）。
  2. 将上面的命令粘贴到窗口中，按回车。
  3. 稍等片刻，脚本会自动下载并显示菜单界面：
    • 选择 1 激活 Windows（HWID 永久激活）
    • 选择 2 激活 Office（Microsoft 365）（Ohook 永久激活）
    • 选择 3 激活其他版本（KMS）
    • 等等…
  4. 根据你的需求输入对应数字，等待提示“激活成功”即可。

注意：激活 Office（Microsoft 365） 需要事先安装好 Office（Microsoft 365） 并确保是批量许可版本（Volume），如果是零售版可能需要先转换。脚本通常也会提供转换选项。

⚠️ 注意事项

虽然 MAS 是一个广受好评的开源项目，但运行任何从互联网下载的脚本都有潜在风险，请务必留意以下几点：

  • 安全风险：irm | iex 模式会直接执行脚本，如果下载的脚本被篡改或 URL 被劫持，可能导致系统受损。建议先查看脚本内容（仅下载不执行）：

    或者去 GitHub 上阅读源码（MAS 项目地址）。

  • 杀毒软件报毒：激活工具常会被杀毒软件误报为“黑客工具”或“潜在不受欢迎的程序”，因为其行为与恶意软件类似（修改系统授权）。如需运行，可能需要暂时禁用实时保护或添加排除项。

  • 版权与法律：激活工具仅供个人学习研究，请支持正版软件。商业用途请购买正版授权。

  • 系统版本要求：Windows 10/11 专业版/家庭版等主流版本均可；Office 支持 2016/2019/2021等；最新的Microsoft 365也可以激活。

最后

一条命令激活 Windows/Office（Microsoft 365） 听起来很酷，但背后是开源社区的努力和透明代码的信任。MAS 脚本简化了激活流程，甚至集成了自动续期、还原等功能，非常实用。当然，无论使用什么工具，都要时刻保持安全意识，并尊重软件开发者的劳动成果。
